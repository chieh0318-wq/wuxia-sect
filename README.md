# wuxia-sect

## 武俠宗門經營（里程碑 2）

唐玄宗開元年間，盛世之下暗藏亂象。師父下山赴「十年之約」後音訊全無，門派又遭逢大變，由你這位大師兄／大師姐帶著殘存的師弟妹另尋山頭、重立門戶。俯視視角經營院落、招收弟子、按月結算，並在江湖大地圖上行旅、打探各方勢力。

1. 在 Unity Hub 選 **Projects → Add → Add project from disk**，選取本專案資料夾，用 **Unity 6000.6.10f1** 開啟。
2. 按編輯器上方的 **Play（▶）**。任何場景都會在進入 Play 模式後自動生成標題畫面與院落。若想建立主場景，可在編輯模式選 **Wuxia → Create Main Scene** 一次。
3. 若要建置 Windows 版，選 **Wuxia → Build Windows (Builds/Win)**，產出 `Builds/Win/WuxiaSect.exe`。

### 操作

**院落**

- **WASD／方向鍵**移動視角，按住**右鍵／中鍵**拖曳，**滾輪**縮放。
- **左鍵**點建築查看資料與指令，點弟子交談，點身穿你所選服色的主角人偶可開啟主角面板。點對話框外即可收起對話。
- 左側「指令」：**興建屋舍**（選建築後點綠色空地）、**招收弟子**、**查看門派**、**主角**、**山道巡訪**。
- 右上 **結束本月**：結算收支、恢復行動力並自動存檔。
- 右下 **江湖地圖　M**／**情報總覽**，或直接按 **M** 開關大地圖。
- **Esc**：關閉月報與對話框；建造時取消建造（右鍵亦可）；其餘時候開啟**設定**（音量）。

**序章與對話**

- 點擊對話框或按**空白鍵**翻頁；右上**略過**可跳過整段劇情（以預設抉擇繼續）。

**江湖大地圖**

- **滾輪**以游標為中心縮放，**右鍵拖曳／WASD** 移動地圖，**全圖**回到全覽。放大後才會顯示次要地名。
- 點**地名**查看路程（天數、行動力、經過路線），按**確認啟程**出發；點**旗幟**查看勢力卡片，未知勢力可**派人打探**（行動力 1）。
- **情報總覽**：點欄名排序（再點一次反向），以類型與關係篩選，點一列即在地圖上定位該勢力據點。
- **Esc** 先關閉情報總覽，再按一次回到院落；**M** 直接返回宗門。

### 主要功能

- **行動力**：每月行動力有上限，建造、招徒、巡訪、旅行、打探都要花費。上限來源（基礎、議事堂等級、年齡、代掌門、天賦、際遇）可將游標移到上方行動力查看；月底全數恢復。
- **新遊戲流程**：首徒稱謂（大師兄／大師姐）→ **外觀**（三種形貌、姓名，旋轉立體預覽）→ 出身 → **天賦**（點數預算、稀有度、重抽）→ **技能**（戰鬥技能與生產技能兩大類，各有 `目前／上限` 階位）→ 屬性 → 插圖**序章** → **門派之變與去留抉擇**（投靠征服者、投靠友好門派或另起爐灶）→ **開局地點**（各有資源、加成與感悟機率）。
- **招收弟子**：公開招徒、江湖尋訪、收養孤兒等方式，候選人有出身、性格、資質（根骨／悟性）、五項屬性、天賦與技能階位；偶有帶著故事的特殊人選。每位新弟子都有隨機的立體外觀。
- **等級上限 C～SS**：`C、B、A、A+、S、S+、SS` 七階，以 `目前 / 上限` 顯示並以顏色區分。武學階位由戰鬥技能推算，奇遇、秘籍、名師指點、閉關可提高上限，神兵利器可使實效階位暫時超越上限。
- **江湖大地圖與情報總覽**：依唐代地理繪製（西域、河西、漠北、吐蕃、南詔、嶺南、江南、河北），標示州城、關隘、門派與勢力範圍。旅行會推進日期，跨過月底時照常進行月結並在返回院落時顯示月報。已打探的勢力、隊伍位置都會存檔。
- **存檔／讀檔**：每月結算與從大地圖返回院落時自動存檔到 `save_slot1.json`（Windows 位於 `%USERPROFILE%\AppData\LocalLow\DefaultCompany\wuxia-sect\`）。標題畫面選**繼續**即可讀取。
- **音量設定**：標題畫面「設定」或院落中按 **Esc**。主音量、音樂、音效滑桿即時生效並記住設定，也可一鍵靜音。院落、大地圖、序章各有配樂，建造、完工、點擊、游標經過、月結、收徒、啟程與抵達都有音效。

### 疑難排解

- **Input System 錯誤**：本專案使用舊版輸入（`UnityEngine.Input`）。請到 **Edit → Project Settings → Player → Active Input Handling** 改為 **Input Manager (Old)** 或 **Both**。
- **肖像或插圖變成粉紅色、方塊或拉伸**：在 Project 視窗對 `Assets/Resources/Portraits` 與 `Assets/Resources/Story` 按右鍵選 **Reimport**，匯入器會把它們設為 2D 貼圖。
- **大地圖空白或沒有音樂**：`Assets/Resources/M2RuntimeAssets.asset` 必須引用地圖與音訊。可執行 `Wuxia.EditorTools.M2BuildAssets.InstallRuntimeAssets` 重新產生。
- **字型顯示為系統字型**：子集字型只包含遊戲用字，缺字時會自動改用系統字型（微軟正黑體）。新增文字後可用 `tools/build_fonts.py` 重建子集。
- **讀檔失敗**：存檔版本不符或檔案損毀時，標題會提示「存檔無法讀取」。刪除上述 `save_slot1.json` 後重新開始即可。
- **沒有聲音**：開啟設定。按鈕若顯示「取消靜音」，表示目前為靜音，按一下即可恢復。另請確認主音量、音樂與音效都不是 0%。

### 資料夾

- `Assets/Scripts/Core` 管理啟動、指令、資源、行動力、月份、存檔、等級與音訊。
- `Assets/Scripts/Data` 定義與讀取 JSON 資料。
- `Assets/Scripts/World` 建立院落、建築、人物模型、視角與大地圖資料。
- `Assets/Scripts/UI` 建立水墨介面、建立角色流程、序章、招徒、大地圖與情報總覽。
- `Assets/StreamingAssets/Data` 存放開局、建築、指令、弟子、序章、天賦、技能、招徒、勢力、地圖與等級資料，欄位見 [SCHEMA.md](Assets/StreamingAssets/Data/SCHEMA.md)。
- `Assets/Editor` 提供主場景、建置與資源設定選單。
- `tools/` 是字型子集、大地圖與音訊的產生腳本。

## M3 創角與人物逸事

- 形貌可切換男女並從肖像格選擇，右側顯示大圖與立體預覽。用方向鍵選擇，滑鼠滾輪或 Page Up／Page Down 翻頁。
- 創角天賦可免費重抽，已選的天賦會保留。
- 招徒與弟子肖像依性別、年齡和出身挑選，優先使用尚未分配的肖像。
- 按 **C** 或點選情報總覽旁的「江湖人物」，可查閱人物小傳、武學階位與技能上限。江湖地圖的勢力卡可由「掌門」直達人物小傳。
- 人物逸事隨月份與劇情條件觸發。抉擇會影響關係與後續發展，進度隨存檔保留。未開放的情節以「後續待續」標示。
